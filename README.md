InterviewAI Coach

Overview

InterviewAI Coach is an AI-powered interview preparation web application that helps students, fresh graduates, interns, and job seekers practice interviews and improve their answers through AI-generated feedback.

Created by: Noor-un-Nisa

Problem Statement

Many candidates struggle with interview preparation, confidence, and identifying weaknesses in their responses. InterviewAI Coach provides realistic interview practice and instant feedback to help users improve before real interviews.

Live Application

Live URL:https://interviewai-coach-six.vercel.app/

Features

- HR, Job, Internship, and Technical interview modes
- Beginner, Intermediate, and Advanced experience levels
- AI-generated interview questions using Gemini AI
- Interactive interview chat experience
- AI evaluation of answers
- Strengths, weaknesses, and improvement suggestions
- Mobile-friendly responsive design

Application Flow

1. Home Page – Introduction and start interview.
2. Interview Setup – Select interview type and experience level.
3. AI Interview Chat – Answer AI-generated questions.
4. Feedback Page – Receive detailed feedback and tips.

AI Feature

The application uses Google Gemini AI to:

- Generate interview questions
- Analyze user responses
- Identify strengths and weaknesses
- Provide improvement suggestions

System Prompt

«You are an experienced interview coach. Generate relevant interview questions based on the selected interview type and experience level. Review the user's answers and provide constructive feedback, strengths, weaknesses, and actionable improvement tips.»

Technologies Used

- Next.js
- Tailwind CSS
- Google Gemini API
- Google AI Studio
- GitHub
- Vercel
